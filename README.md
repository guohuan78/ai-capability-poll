# AI 能力认知现场投票

手机匿名投票，浏览器实时展示统计，用于一次组会中的 AI 能力认知讨论。

- [现场统计](https://guohuan78.github.io/ai-capability-poll/)
- [参与投票](https://guohuan78.github.io/ai-capability-poll/vote.html)
- [主持台](https://ai-capability-poll-api.prime-daisy-7276.chatgpt.site/admin)

## 使用

默认打开现场统计，展示每个选项的人数和占参与人数的比例。点击全屏展示可用于投影。参与者扫描统计页二维码，或点击“参与投票”，用手机选择并提交。统计页每两秒读取一次共享后端。`present.html` 兼容跳转到默认统计页。

主持台使用创建网站的 ChatGPT 账号登录，可开放、结束投票，或清零开始新一轮。统计页与参与页不要求登录。

## 现场连接

2026 年 10 月 19 日的现场配置优先通过电脑上的 HTTPS 中转访问共享后端，原 Worker 地址作为备用入口。手机使用移动网络直连中转；主持台仍使用原地址。

中转运行期间，主持电脑、电脑代理、本地转发程序与 Cloudflare Tunnel 窗口都需要保持运行，电脑需保持联网且不休眠。临时中转重启后地址会改变，需将新地址写入 `config.js` 的 `apiBase` 并重新发布。原地址备用是否可用取决于参与者网络，中转中断时不能保证所有手机自动恢复。

两个入口读写同一份投票数据。切换入口时复用相同的匿名编号、本轮编号及提交序号；重新提交会更新答卷，不增加参与人数。页面会忽略较旧的统计响应，保持轮次和统计状态一致。

## 统计口径

题目与当前组会 PPT 第 5 页一致：给定目标、资料与必要环境，AI 自主交付可用成果。A–J 可多选，K、L 各需单独选择，且与其他选项互斥。每个选项占比的分母是参与人数，各项比例合计可超过 100%。同一浏览器可修改选择，更新答卷不会增加人数。浏览器随机编号用于普通重复提交去重，不代表实名一人一票。

当前题目使用独立的答卷记录；旧题答卷保留在后端，不计入当前统计。

前端托管于 GitHub Pages；共享数据由独立 Worker 与 D1 保存，公开配置只包含服务地址。公开仓库不包含管理密钥、实习材料或论文文件。
